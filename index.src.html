指令集与语义（包内规则的实现说明）
指令语义
[常量,目标,数值]四格全部写入数值常量；操作数也允许直接写数值。
[加/乘,目标,甲,乙]逐格算术。
[细横,目标,源]所在行右减左：LT/RT 用 RT−LT，LB/RB 用 RB−LB。
[细纵,目标,源]所在列下减上：LT/LB 用 LB−LT，RT/RB 用 RB−RT。
[粗横,目标,源]全四格用顶行 RT−LT。
[粗纵,目标,源]全四格用左列 LB−LT。
[舍弃,甲,乙]甲 < 乙 时置该格舍弃标记；不写寄存器。
[纹理,目标,u,v,通道]用当时坐标的细导数换算基底纹素，ρ=max(|∂x|,|∂y|)，LOD=clamp(log₂ρ,0,L)，零导数取第 0 层；双线性按 u·w−0.5、v·h−0.5 取周期邻点，层间线性混合。

未覆盖与已舍弃的辅助格继续执行全部指令、照常参与导数与舍弃判断；只有「已覆盖且未舍弃」的片元参与深度选择，深度小者胜，同深度取小 id（再同则按输入顺序/车道编号）。

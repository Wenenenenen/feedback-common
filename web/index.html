实现公式（与样例包说明一致，无现成渲染器）

变换：均值 μ꜀ = V·M·μ；协方差 Σ꜀ = A·Σ·Aᵀ，A = (VM) 的线性 3×3

投影：u = fx·x/z + cx，v = cy − fy·y/z（像素中心 +0.5）

雅可比：J = [[fx/z, 0, −fx·x/z²],[0, −fy/z, fy·y/z²]]

屏幕协方差：C = J·Σ꜀·Jᵀ + 0.25·I（2×2 对称，含剪切交叉项）

门控：q = dᵀ·C⁻¹·d，q > 9 不参与；中心 z ∉ [near, far] 整点剔除

α = min(0.99, opacity·exp(−q/2))

合成：按 z 升序（等深按字符串 ID），w = T·α，RGB += w·c，T ← T·(1−α)，末加 T·bg；不提前终止

期望深度 = Σ(w·z) / Σw；Σw = 0 → null

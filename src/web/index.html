    5 · 诊断

      约定

      • 解 t-u = ‖S(u)-E(t)‖，取 u∈[start,end) 且 u≤t。
      • q = u-start+offset，floor(q) 与后一样本线性插值；后一样本越过段引用末尾记 0。
      • 每项增益 8/(8+d)，同耳求和后四舍五入（.5 远离零）并夹到 int16。

采样格谱约定
JSON 根对象为 {channels,bpm,speed,samples,patterns,order}。channels 为 1 至 32，bpm 为整数 32 至 384，speed 为整数 1 至 32。samples 至多 32 项，每项为 {pcm,loop}。pcm 为长度 1 至 48000 的有符号 16 位整数数组。loop 为 null 或整数半开区间 [lo,hi)，在 pcm 内且 lo < hi。
patterns 是花样数组，至多 256 张，每张是 1 至 64 行的数组。order 为 1 至 512 个花样下标。每次进入编排位置默认从第 0 行起。每行对象可有 bpm、speed、back、break、voices，省略的 bpm 和 speed 沿用前值。back 为 [目标行,额外回跳次数]，目标必须早于当前行，次数为 1 至 64。计数按编排位置与命令所在行分别保存，同一次编排位置中耗尽后不重置。行结束若有剩余回跳就消耗一次并跳转，其次才处理 break。break 是下一编排位置的入行下标，若没有下一位置则结束，若有而入行越界则是非法编辑。未跳转的行顺序前进，花样到尾就进入下一位置。
全局时钟从 0 起，每个 tick 时长为 120000/bpm 个输出采样帧。每行恰有 speed 个 tick，从 0 编号。每个 tick 持有从精确累计起点向下取整到精确累计终点向下取整的半开采样区间。实际执行至多 20000 tick，向下取整后的总长至多 8640000 帧。
voices 省略或为列表，元素为 {ch,note,delay,retrig,slide}，ch 在当前行不重复，索引从零开始。note 省略或为 [采样下标,整数步长]，步长以 1/65536 源采样为单位，范围 1 至 1048576。delay 只有带 note 才可设置，默认 0，必须小于实际行速。retrig 可省略，设置时为 1 至 32，表示本行从第 1 个 tick 起每逢其倍数重置仍在响的声部相位至 0。slide 可省略，设置时为绝对值不超过 1048576 的整数。非零 slide 在行开始保存到本声部，零取该声部记忆值，初始记忆为零。没有 slide 的一行不做滑音。
每 tick 先在指定延迟处触发新音并置相位为 0，未触发新音的声部再按规则重触发，随后在编号大于零的 tick 给仍在响且本行有 slide 的声部加滑音量，步长夹到合法范围。一个新音替换该声部的前音，不清空滑音记忆。日志显示每声部的新音、重触发或无触发，以及调度后、该 tick 首个输出帧前的采样编号、相位和步长，并记录行末的跳转结果。
每帧按当前 Q16 相位线性插值后递增步长。循环采样从 0 播，循环最后一个采样与 lo 点插值，递增后越过 hi 的量按循环长度取余再加 lo，可以一次越过多圈。非循环采样的最后一点与零插值，越尾后关闭声部。各声部的插值相加一次，再按最近整数舍入，刚好半格时远离零，最后夹到 PCM16。WAV 输出为 48kHz PCM16 单声道。区间按全曲零基半开采样帧选择，试听比对送给播放器的 PCM，日志保留绝对 tick 与采样帧，列出与所选半开范围相交的 tick。

# 回滚格斗联机实验室

双人格斗小游戏的回滚（rollback netcode）联机调试台。两个模拟客户端在同一页内运行，
可设置单向延迟、抖动、丢包与回滚深度上限，把“本地输入立即生效 → 远端输入未到时预测 →
猜错后从该帧回滚重算”的完整过程摊开来看。

逻辑全部用**整数**，不使用浮点、`Math.random` 或任何非确定 API。同一份输入日志每次跑出的
逐帧校验和完全一致。

## 运行

页面是纯静态站点，无需构建：

```bash
cd rollback-lab
python3 -m http.server 8923 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8923/
```

直接双击 `index.html` 也能运行（所有依赖均为本地相对路径，字体走 Google Fonts，
离线时回退系统字体）。

## 规则实现要点（对应《格式说明.md》）

- **帧号从 0 开始**，固定 60fps；坐标单位 1/100 像素，场地 0..60000，不跳跃。
- **每帧三段结算**：①两人各自推进（基于帧开始快照，互不影响）②命中结算（同时判定、
  同时生效）③KO 判定，之后状态冻结但帧号照常增加。
- **朝向**按帧开始位置取，x 相等时 P1 朝右 P2 朝左；后退方向据此判定格挡。
- **格挡**要求帧开始时为 idle/walk 且本帧按住后退；格挡不掉血，进入 blockstun。
- **命中**要求有效帧、本招未命中过（`connected`）、距离不超过 reach；同帧互击都生效；
  同一招只命中一次。被命中会打断正在出的招。
- **校验和**：对 `f|x1|hp1|act1|actFrame1|stun1|x2|hp2|act2|actFrame2|stun2` 的 UTF-8 字节
  做 FNV-1a 32 位哈希（初值 2166136261，乘数 16777619），输出 8 位小写十六进制。

## 联机模型

- 延迟按 `ceil(60·ms/1000)` 折算成整数帧；抖动在 `[0, jitterFrames]` 内取整数；丢包按
  整数百分比判定。所有随机来自带种子的确定性 LCG，同种子逐位复现。
- `NetworkLink` 内部是**两条独立单向通道**，各自独立计时与随机源；链路每帧统一 tick 一次，
  避免两个客户端重复推进同一通道的帧号。
- 每个数据包冗余携带发送方全部已确认输入，丢包只丢副本，后续包会补全，输入不会永久丢失。
- 远端输入未到时，沿用最近一次已确认输入预测（首帧默认 0）。收到真实输入后：
  - 预测值与真实值相同 → 仅把该帧提升为“已确认”，不回滚；
  - 不同 → 从第一个猜错的帧载入快照回滚重算。
- **回滚深度上限**：本地帧领先最早未确认帧达到 `rollbackMax` 时暂停推进，等待输入到达。
- **事件对账**：命中/格挡事件按“帧号+攻击方”建键。回滚重算后仍发生的事件不重复触发特效，
  不再发生的事件标记为“已撤销”并在画面与时间线中划线撤掉。
- **分歧判定**：只有两边都确认了同一帧、校验和却仍不同，才算真分歧（预测中的瞬时不一致
  会在输入到达后自愈，不算）。出现真分歧时停在第一处并列出两边角色字段差异。

## 页面操作

- 顶部设置网络参数与回滚上限，选择样例后“开始/重置”。可调步进速度或一次跑到底。
- 空格暂停/继续，`→` 单步，`R` 重置。
- “停在首处分歧”开关决定遇到真分歧时是否自动停机。
- 导入日志须符合 `{"start":{…可选},"frames":[[p1,p2],…]}`，输入为 0–15 位掩码；
  非法日志会被拒绝并指出具体帧与玩家。
- “导出输入日志”保存当前日志；“导出逐帧状态 JSON”保存参考实现逐帧状态、两边客户端
  校验和/预测标记/事件/统计与网络元数据。
- “运行自测”在浏览器内执行与 Node 相同的 14 项用例。

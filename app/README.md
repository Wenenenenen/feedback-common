# 时域历史重投影校验台

一个纯前端的时域抗锯齿（TAA）历史重投影教学与校验工具。重投影、逐采样点深度拒绝、
邻域限幅、历史计数全部自行实现，**不调用任何现成 TAA 接口**。

## 运行

模块 Worker 必须经 http 协议加载（`file://` 下浏览器会拒绝模块 Worker），用内置零依赖服务器：

```bash
cd app
npm run serve          # http://127.0.0.1:8123
```

或任意静态服务器，例如 `python3 -m http.server`，根目录指向 `app/`。

## 页面功能

- **三视图并排**：当前帧（线性 RGB→sRGB）、累积结果、逐像素拒绝原因分类图。
- **帧导航**：首/末/上一/下一帧、可拖拽或输入帧号任意跳转、可调速播放（支持循环）。
- **像素检视**：点任一画布像素，查看历史位置、双线性四个采样点、原始/归一化权重、
  每点有效状态与原因、加权历史 H、3×3 邻域 min/max、限幅后 H、混合系数 a、混合前后 RGB 与计数。
- **可调参数**：深度阈值 `tau`（0–0.5，默认 0.05）、历史权重 `w`（0–0.99，默认 0.9）、
  计数上限 `cap`（1–64，默认 8）。任何改动都从第 0 帧全量重算，结果与从头计算一致。
- **导出**：选定帧 PNG（线性值夹到 [0,1] 后按标准 sRGB 传递函数编码）、
  线性浮点 JSON（含尺寸、帧号、参数、颜色、计数）、所选像素的追踪 JSON（全帧历史位置/采样点/权重/数值）。
- **响应不卡顿**：计算在 Web Worker 内按像素分批、帧间让出事件循环；大缓冲零拷贝 Transfer。
  改参数或取消会即时中断旧任务。页面内置「一致性自检」抽样比对 Worker 与主线程从头重算结果。
- **数据接入**：内置样例可直接选；也可上传符合约定的 `.json` 或 gzip 压缩的 `.json.gz`，
  结构不符时给出逐字段错误（`invalid.json` 即错误示例）。

## 算法约定（与样例包 `说明.txt` 一致）

对第 f 帧像素 p（像素中心 `(x+0.5, y+0.5)`）：

1. 当前深度为 `null` → 直接输出当前色、计数 1。
2. 历史位置 = 像素中心 + `motion`（当前→前帧、不含抖动）+ 前帧 jitter − 当前 jitter。
3. 以历史像素中心做双线性，得到 4 个采样点；每个点仅当
   - 落在图内，且
   - 两帧深度均非空，且
   - `|当前深度 − 该点前帧深度| ≤ tau · max(1, 当前深度)`

   时有效；有效点权重重新归一化。
4. 无有效点 → 输出当前色、计数 1，并记录具体原因（越界 / 历史深度空 / 深度拒绝）。
5. 有有效点：`H`、`n` 分别为有效点上一帧累积色与计数的加权值；
   `H` 按当前帧图内 3×3 邻域逐通道 min/max 限幅；
   `a = min(w, n/(n+1))`；输出 `(1−a)·当前色 + a·限幅H`；新计数 `min(cap, n+1)`。
6. 第 0 帧计数 1，直接输出当前色。

## 目录结构

```
app/
├── index.html              页面结构与设计系统
├── src/
│   ├── core.mjs            纯算法核心（无 DOM，可在 Node/Worker 复用）
│   ├── worker.mjs          分批调度 Worker，runId 由主线程统一分配
│   ├── render.mjs          画布绘制、sRGB 编码、标记、PNG/JSON 导出
│   └── app.mjs             主控制器：加载、调度、播放、检视、导出
├── sample-data/            内置样例（capacity 另附 .gz 侧载）
├── reference/
│   ├── reference_reproject.py   独立 Python 参考实现
│   ├── gen_snapshots.py         生成跨语言校验快照
│   └── snapshots/               生成物（gitignore，可重新生成）
└── test/
    ├── cross-check.mjs     JS 与 Python 参考逐像素比对（约 1490 万项）
    ├── worker-pipeline.mjs 分批管线与全量计算一致性
    ├── ghosting-check.mjs  留影阻断 / 全拒重置场景
    ├── browser-smoke.mjs   Playwright 端到端（真实 Worker、交互、导出）
    ├── screenshot.mjs      截图
    └── serve.mjs           本地静态服务器
```

## 测试

```bash
npm run snapshot     # 先由 Python 参考实现生成快照（需 python3）
npm test             # 跨语言比对 + 管线 + 场景 + 浏览器端到端
```

- `cross-check`：3 个序列 × 4 组参数（含 0/最大值等边界），逐像素比对 RGB、计数、原因枚举，
  容差 1e-10。JS 与 Python 两套独立实现结果一致。
- `ghosting-check`：物体移走当下，落在旧物体上的历史采样点全部深度拒绝、物体颜色零漏入，
  背景点归一化后继续累积；四采样点全拒时计数重置为 1。
- `browser-smoke`：15 项端到端断言，覆盖真实 Worker 计算、播放、跳转、参数全量重算、
  自检、三类导出与错误数据拦截，且全程无控制台错误。

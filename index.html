计算口径

逆扫频 g[j] = x[N-1-j]·exp(-j·ln(f1/f0)/N)，0 ≤ j < N。定标 D = (x∗g)[N-1] = Σ x[k]²·exp(-(N-1-k)·ln(f1/f0)/N)；D 为 0 报错。每条采集 c = (y∗g)/D，∗ 为线性卷积（实数 FFT 实现，长度取 ≥ M+N-1 的 2 的幂）。

零点取搜索区间 [N-1+lo, N-1+hi] 内 |c| 最大帧，同高取较早帧。第 q 阶中心 zero - floor(N·ln(q)/ln(f1/f0) + 0.5)，q = 1…4。窗 [中心-pre, 中心+post)，超出反卷积索引的样本取零；两窗半开区间有公共样本即为冲突。能量为窗内样本平方和。

导出的浮点 WAV 按窗口样本原样写出（含补零），采样率 48 kHz，单声道，float32，不峰值归一、不限幅。

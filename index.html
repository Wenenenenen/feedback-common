    算法与约定
    

      

        
姿态定义

        
以锚点为原点：先水平镜像（可选），再缩放，最后在 x 向右、y 向下的坐标中顺时针旋转并平移。角度单位为度，范围 −180°…180°。

      

      

        
配对规则

        
模板边点与场景边点配对需距离 ≤ 2.5 px 且法向夹角 ≤ 45°。法向取 Sobel 梯度方向、指向亮侧。每个模板点取满足条件的最近场景点。

      

      

        
覆盖率

        
覆盖率 = 配对成功点数 ÷ 全部模板边点。分母包含投影出图像外的点与被遮挡点，所以遮挡只降低分数，不会让比较基准缩小。

      

      

        
四步流程

        
    
          
  1. 方向霍夫投票：按法向分箱，在 (镜像, 尺度, 角度) 组合上为平移投票，保留峰值。
    2. 
          
  2. 精确配对评分：每个候选逐点做距离与法向双条件配对，得到覆盖率与均距。
    3. 
          
  3. 姿态细化：只用已配对点做阻尼 Gauss–Newton，更新平移、角度、尺度。
    4. 
          
  4. 证据去重：位置/姿态近邻只报一次；若两姿态配对到同一批场景边点，保留证据更强的一个。

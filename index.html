# start end tick 数 起点 tempo 补足 输出 tick 片段 µs 累计 µs 操作

「补足」是这一片段里被切点截断、需要补出起止事件的音符数。衔接处同一轨的 note-off 会排在 note-on 之前，避免挂音。

剪辑清单 / MANIFEST — 输出 tick 与累计微秒
剪辑清单的片段输出时刻与累计时长
片段 源区间 输出 tick tick 数 起点 tempo 片段 µs 累计 µs 精确累计

处理约定　note-on / note-off 按（轨、通道、键号）FIFO 配对，零力度 note-on 视为 note-off；片段为左闭右开区间，音符按交集裁切并补合成起止事件；同轨同 tick 先关后开；tempo 取片段起点正在生效的值，未设定时为 500000 µs / 四分音符；时长按 tempo 分段以整数分数累计，最后一步才向下取整到微秒。

输出　1 型 MIDI：第一轨为速度表，其后保留有音符的源轨道、通道、力度与 PPQ；所有轨道结束事件落在输出总长度上，尾部休止不会被截掉。剪辑清单列出每段输出 tick 与累计微秒，并附精确分数。

    格式说明

    配对规则：每对像素 (x, y) 记 l = ⌊(x+y)/2⌋、h = x−y，把 h 换成 2h+b 后还原两像素； 两种载荷位嵌入后都不越出 [0,255] 且两像素均被掩膜获准，该对才可用。 按 8×8 块划分（边缘块截断），每块分别试横向与纵向的不交叠相邻配对（从块左上起配）， 取可用容量大的方向，同数取横向。写入顺序：块行序 → 块内首像素行序 → 十六进制载荷每字符 4 位、高位在先。

    旁车 JSON 字段：image（宽高）、bitCount（位数）、payloadHex（载荷）、 originalCrc32（原栅格 CRC32）、maskCrc32（掩膜 CRC32 或 null）、 pairs（已用坐标 [x1,y1,x2,y2]）。读回时先从标记图按坐标提取并还原原图， 再校验 CRC32，并用还原原图与同一掩膜重算配对规则核对坐标，全部通过才开放下载。

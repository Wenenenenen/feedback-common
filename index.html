    怎么用

    • 尺寸切换：尺寸 1/2/3 分别按 1×1、2×2、3×3 占块计算可通行区与积分场。
    • 图层：可叠加代价场（平地 1 / 泥地 3）、积分值热力、方向箭头、数值、可通行区、受影响区、单位、目标格。尺寸 2/3 会淡色铺出锚点代表的 k×k 占块。
    • 查看数值：点击任意格子，右侧显示该格的字符、代价、三种尺寸下的可通行性与积分值。
    • 改地形：开启“改地形”后点或拖动格子切换墙/平地/泥地/目标，只重算受影响区域；“受影响区”图层会高亮重算过的锚点，右侧显示失效锚点数与耗时，并自动用全量重算核对一致性。
    • 逐帧播放：单位按 id 升序每帧最多走一格；到不了的单位、被堵死的单位会在统计里单独标出。
    • 导出：积分场按原图坐标行优先输出，不可达为 null；轨迹 JSON 含每帧位置与每个单位的到达帧，另附不可达/被堵死的单位列表。
    • 自检：顶栏“自检”会复跑参考数据对照、增量与全量一致性、模拟不变量（不穿墙、不重叠、每帧至多一格）。
    • 快捷键：← / → 逐帧，空格 播放/暂停。

鞍点等值线图集

Marching Squares · Q 判据 · 掩膜开放线
输入与参数
点击选择或拖入灰度 PNG 每边 2–1024 节点 · 灰度 color type 0
点击选择或拖入掩膜 仅四角均有效的单元参与提线
节点为整数，半整数阈值不会落在节点上
修改后画布与导出的物理坐标、长度、面积同步重算
约定
  • 鞍点四交点：Q=(a−t)(c−t)−(b−t)(d−t)
  • Q>0 连上-右 / 下-左；Q≤0 连上-左 / 右-下
  • 共享网格边按边身份复用同一交点，不做坐标去重
  • 触图边或掩膜的线保持开放，不自动封口
画布
导入一张 16 位灰度 PNG（可再加掩膜），
调整阈值与物理参数后点击「提取等值线」。

点击画布中的单元查看角点、交点与连接选择；
点击折线查看点数、开闭、物理长度与闭环面积。
